# Start here

Want this IPO tracker on your phone's home screen, working anywhere
(not just your home Wi-Fi), for free, forever?

👉 Open **DEPLOY.md** and follow it top to bottom. It's written for
someone with no coding background — just copy/paste and click-through
steps (GitHub → Render → your phone).

If you get stuck at any step, come back to this chat with the exact
screen you're stuck on and the error text (if any) — that's the fastest
way to get unstuck.

---

For technical background on how the app itself is built (what each
folder does, how refresh timing works, etc.), see **README.md**.
